# matt-cardona-vs-nick-gage-ja-subs

YouTube 動画 [The Untold Story of Matt Cardona vs. Nick Gage | The Deathmatch That Changed Wrestling](https://www.youtube.com/watch?v=cyDHY2jMM4k) の日本語字幕 (SRT) を作るプロジェクト。

- 動画は自分のものではない。字幕ファイルのみを作り、動画の所有者に提供を申し出る
- 元動画に英語・日本語とも手動字幕はない (自動生成のみ)
- 作者は英語話者ではないため、AI ツールで聞き取り・翻訳を補い、人間は確認に集中する

## 進め方

| # | 工程 | 方法 | 成果物 |
|---|------|------|--------|
| 1 | 音声取得 | `yt-dlp` で音声のみ取得 (個人利用) | `*.mp3` |
| 2 | 英語書き起こし | Whisper (`faster-whisper` / `whisper.cpp`) で SRT 出力。YouTube 自動字幕と突き合わせて食い違い箇所だけ聞き直す | `en.srt` |
| 3 | 英語の校正 | LLM に固有名詞 (レスラー名・団体名・試合名) の用語集を渡して校正。不確かな箇所は人が音声で確認 | `en.srt` (校正済み) |
| 4 | 日本語訳 | LLM で翻訳。番号とタイムコードは変更せず、テキストだけ差し替える。用語集を併用して訳語を統一 | `ja.srt` |
| 5 | タイミング調整・確認 | Subtitle Edit または Aegisub で波形を見ながら調整。`mpv --sub-file=ja.srt` で最初から最後までプレビュー | `ja.srt` (完成) |
| 6 | 提供 | 動画の所有者へ字幕の提供を申し出る (YouTube の「コミュニティ字幕」または直接連絡) | - |

## 方針

- タイムコードは Whisper が出したものを基準にする。翻訳工程では触らず、機械的に検証する (番号・時刻が `en.srt` と一致するか)
- 1 行の文字数と表示時間に上限を設ける (目安: 1 行 20 字前後、2 行まで、1 秒あたり 4〜5 字程度)
- 固有名詞の用語集 (`glossary.md`) を作り、書き起こし・翻訳の両方で参照する
- 不確かな箇所には `[?]` を付け、後でまとめて確認する

## ディレクトリ構成 (予定)

```
.
├── README.md

├── en.srt           # 英語書き起こし
├── ja.srt           # 日本語字幕
└── scripts/         # SRT の検証・変換用スクリプト
```
